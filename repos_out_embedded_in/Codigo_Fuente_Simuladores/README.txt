Gemelos Digitales Hidrodinámicos 3D - UTP
=========================================
Autor: Rafael Sanchez Rueda
Universidad Tecnológica de Pereira (UTP)
Facultad de Ingeniería Mecánica

Este directorio contiene el código fuente de los simuladores 3D desarrollados para la asignatura Laboratorio de Fluidos y Máquinas Hidráulicas.

Requisitos Previos:
-------------------
Para ejecutar la plataforma localmente, es indispensable tener instalado Node.js en su sistema.
1. Descargue e instale Node.js (versión 16 o superior) desde la página oficial:
   https://nodejs.org/
2. Verifique la instalación abriendo una terminal y escribiendo:
   node -v
   npm -v

Instrucciones de Ejecución:
---------------------------
1. Abra una terminal de comandos (CMD o PowerShell) y navegue hasta esta misma carpeta (Codigo_Fuente_Simuladores).
2. Instale las dependencias del proyecto ejecutando:
   npm install
3. Inicie el servidor local de desarrollo ejecutando:
   npm run dev
4. Abra su navegador web en la dirección que indique la terminal (por defecto suele ser http://localhost:5173/).

Tecnologías Utilizadas:
-----------------------
- React.js y React Three Fiber
- Three.js (WebGL) y GLSL Shaders
- Tailwind CSS
